The periodic table is a table that puts all known chemical elements in a specific order. Elements that have similar characteristics are often put near each other. In the table, the elements are placed in the order of their atomic numbers starting with the lowest number of one, hydrogen. The atomic number of an element is the same as the number of protons in that particular nucleus of an atom.
