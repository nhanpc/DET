An electric guitar is a type of musical instrument. The first one was made in 1931 by George Beauchamp. It is a string instrument usually played with a pick and sometimes with the fingers. It uses things called "electric pickups" which are wire-wound magnets that change the vibration of the strings into electric current. This electric current is then sent to an amplifier (amp for short) that changes it to sound.
